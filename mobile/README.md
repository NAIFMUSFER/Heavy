# JANA Mobile

تطبيق عميل React Native / Expo منفصل عن موقع الويب، ويستخدم API الإنتاج نفسه عبر Bearer access token.

## الموجود حاليًا

- متجر المنتجات والسلال من قاعدة JANA الحية.
- سلة محلية محفوظة على الجهاز.
- تسجيل دخول وإنشاء حساب، مع حفظ access token في Expo SecureStore.
- العناوين، التحقق من التغطية، المواعيد المتاحة، إنشاء Quote وتأكيد طلب COD.
- قائمة الطلبات وتفاصيلها، ومعالجة قرار البدائل المعلقة.
- حماية طلبات التغيير بـ Idempotency-Key؛ الطلبات عبر Bearer لا تعتمد على CSRF الخاص بالويب.

## التشغيل المحلي

استخدم Node 24 وملف الاعتماديات المحفوظ. لا تغيّر إصدارات الحزم خلال بناء الإصدار.

```bash
cd mobile
npm ci
npx expo start
```

API الافتراضي: `https://jana-fresh-app.onrender.com`.

## حالة الإصدار

نجح بناء APK اختباري ونجح تجميع تطبيق iOS للمحاكي في GitHub Actions. لم يُختبر التطبيق بعد على جهاز فعلي ولم يُنشر في App Store أو Google Play. توقيع التوزيع وحسابات المتاجر مطلوبة من المالك. تُعاد بوابات البناء عند تغييرات الجوال؛ راجع دليل الإصدار لحالة كل نسخة.

تُحفظ حزمة Android debug وحزمة iOS Simulator كملفات في نتائج GitHub Actions لمدة سبعة أيام. حزمة iOS للمحاكي فقط؛ التثبيت على iPhone يحتاج توقيع Apple. نجح البناء المقفل في Android 34466248708 وiOS 34466248711 وExpo 34466248726. روابط الملفات في تقرير التسليم.
