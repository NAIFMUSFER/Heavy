# JANA Mobile

تطبيق عميل React Native / Expo منفصل عن موقع الويب، ويستخدم API الإنتاج نفسه عبر Bearer access token.

## الموجود حاليًا

- متجر المنتجات والسلال من قاعدة JANA الحية.
- سلة محلية محفوظة على الجهاز، مع التحقق من بياناتها وترتيب عمليات الحفظ وإعادة المحاولة عند فشل التخزين، ومسح صريح لسلة الجهاز عند الحاجة.
- تسجيل دخول وإنشاء حساب، مع حفظ access token في Expo SecureStore.
- العناوين، التحقق من التغطية، المواعيد المتاحة، إنشاء Quote وتأكيد طلب COD.
- قائمة الطلبات وتفاصيلها، ومعالجة قرار البدائل المعلقة.
- استعادة مراجعة الشراء بعد إغلاق التطبيق، والتحقق من نتيجة تأكيد انقطع رده، وإظهار مهلة الحجز من توقيت الخادم.
- إلغاء حجز عرض السعر صراحةً، وحفظ السلة المعدّلة، ومنع الردود المتأخرة من إحياء مراجعة جلسة انتهت.
- إعادة تحميل الحساب بعد فشل الاتصال دون ربط نجاحه بسلامة تخزين السلة. قبول الأرقام العربية والفارسية في مبالغ الاسترداد وكميات القوائم والتقييم والتذكير، مع رفض تقريب مبالغ ذات منازل عشرية زائدة.
- حماية طلبات التغيير بـ Idempotency-Key؛ الطلبات عبر Bearer لا تعتمد على CSRF الخاص بالويب.

## التشغيل المحلي

استخدم Node 24 وملف الاعتماديات المحفوظ. لا تغيّر إصدارات الحزم خلال بناء الإصدار.

```bash
cd mobile
npm ci
npx expo start
```

API الافتراضي: `https://jana-fresh-app.onrender.com`.

## حالة الإصدار

نجح بناء APK اختباري ونجح تجميع تطبيق iOS للمحاكي في GitHub Actions. لم يُختبر التطبيق بعد على جهاز فعلي ولم يُنشر في App Store أو Google Play. توقيع التوزيع وحسابات المتاجر مطلوبة من المالك. تُعاد بوابات البناء عند تغييرات الجوال؛ راجع دليل الإصدار لحالة كل نسخة.

تُحفظ حزمة Android debug وحزمة iOS Simulator كملفات في نتائج GitHub Actions لمدة سبعة أيام. حزمة iOS للمحاكي فقط؛ التثبيت على iPhone يحتاج توقيع Apple. [سجل الإصدار](../docs/RELEASE-EVIDENCE.md) يحدد المصدر المختبر وروابط أحدث النتائج وصلاحية ملفاتها، ويُميّز البناء الناجح من النشر في المتاجر.
